QLCUAHANG - PHAN CODE THANH VIEN 1

Yeu cau:
- XAMPP (Apache + MySQL)
- PHP 8.x
- Trinh duyet web

CAI DAT:
1. Giai nen thu muc QLCuaHang vao C:\xampp\htdocs\
2. Mo XAMPP Control Panel, bam Start cho Apache va MySQL.
3. Mo http://localhost/phpmyadmin
4. Chon Import, chon file database/qlcuahang.sql, bam Import.
5. Mo http://localhost/QLCuaHang/auth/seed_admin.php MỘT LAN de tao tai khoan mau.
6. XOA file auth/seed_admin.php sau khi tao tai khoan.
7. Mo http://localhost/QLCuaHang/auth/login.php

Tai khoan mau:
Ten dang nhap: admin
Mat khau: Admin@123

Luu y:
- Doi mat khau mau sau khi dang nhap (chuc nang doi mat khau chua duoc lam trong ban dau).
- Vai tro mau: Admin, Manager, Staff, Warehouse Staff.
- KHACHHANG trong bao cao la khach mua hang, khong phai tai khoan dang nhap nhan vien.
- Cac muc menu la khung dieu huong; cac thanh vien khac se tich hop chuc nang vao sau.
